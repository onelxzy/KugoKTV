# 酷唱 KTV - Android TV 端本地点唱与伴唱软件

这是一个专门为智能电视和 Android 电视盒子设计的独立 KTV 客户端，基于酷狗 MV 接口和本地实时音频处理技术（差分人声消除）。

---

## 🌟 核心功能

1.  **超清 MV 点播**：
    *   直接对接酷狗 MV 搜索和播放直链接口，免登录，无广告，首选 FHD 1080p 超清画质。
2.  **本地零延迟消音（去除人声）**：
    *   通过自定义 Media3 `AudioProcessor` 对实时双声道 PCM 数据进行左右声道差分处理：
        $$\text{伴奏信号} = \frac{\text{左声道} - \text{右声道}}{2}$$
    *   一键物理抵消处于声场正中心的歌手人声，几乎不耗盒子 CPU 算力，点播即可秒切伴奏。
3.  **独立伴奏音量衰减**：
    *   仅在播放器内部缩减伴奏音量，不影响 Android 系统的主音量，保证插在电视盒上的 USB 麦克风输入与混响音量宏亮。
4.  **局域网无线点歌**：
    *   电视端启动时会自动起一个轻量级 Web 服务器（基于 Ktor，默认监听 **`19985`** 端口），并在屏幕左下角输出二维码。
    *   手机与电视连入同一 Wi-Fi，扫码即可打开手机专属点歌台 H5 网页进行远程搜歌、切歌、调音量及控制伴奏原唱切换。
5.  **遥控器焦点优化**：
    *   针对电视遥控器十字方向键进行了深度适配，UI 卡片具有缩放高亮和外发光动画，操作流畅明确。
6.  **无 MV 纯音频备用模式**：
    *   当检索曲库没有对应的 MV 时，App 会自动请求高清音频直链，并在屏幕中循环播放精美粒子背景，不损坏电视屏幕（防烧屏），并同样支持差分消音。

## 🛠 开发与编译

### 方式一：Android Studio 本地编译
1.  下载并安装最新版的 **Android Studio**。
2.  在 Android Studio 中选择 `Open` 并选择本项目根目录 `KugoKTV`。
3.  项目将自动下载全部依赖（Media3, Ktor, OkHttp, ZXing 等），同步完成后直接连接电视盒子（通过 USB 或局域网 `adb connect`）运行调试。

### 方式二：GitHub Actions 自动打包
本项目已配置了 `.github/workflows/android-build.yml` 的 CI 工作流。
1.  在 GitHub 上新建一个仓库。
2.  将本项目代码 push 到你的 GitHub 仓库。
3.  进入 GitHub 的 Actions 页面即可直接手动触发或在每次 push 时自动编译打包出正式签名的 `.apk` 文件。
